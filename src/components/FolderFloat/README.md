# FolderFloat

Source: https://reactbits.dev/r/FolderFloat-JS-CSS.json (2026-10-12), dependency matter-js.
Adaptations: folder-open callback, drag suppression, delayed hover close, keyboard focus, viewport-edge placement and safe parent callbacks.
Promi uses the first three ordered records in each folder, with physics disabled for predictable clicking.
Shared CSS import also supports the extension Shadow DOM.

# Promi 提示词管家 v1.5.0

## 新增与优化

- 选中文字后显示紧凑工具栏，支持 B 加粗、背景高亮、文字颜色、复制选区和清除格式。
- 提供十组阅读配色，以及自定义色相／饱和度／明度、HEX 和背景透明度；支持日夜预览与对比度提示。
- 原文实时预览，确认后保存、取消恢复；色板避让选区，窄窗口自动限制高度，拖动按动画帧合并更新。
- 格式与正文分开保存，关闭重开及 ZIP 导入／导出保留，复制和模型请求仍是纯文字。
- 修复跨行拖选后在正文框外松手漏触发工具栏的问题，阅读与编辑状态都可使用。
- 保留 v1.4.0 的果冻状态反馈、macOS 置顶工作台及图片复制等功能。

## 安装

下载本页的 **Promi 测试包 ZIP 附件**并解压。在 Chrome／Edge 扩展管理页开启“开发者模式”，点击“加载已解压的扩展程序”，选择包内的 `extension` 文件夹。无需 Node.js 或源码构建。不要下载 GitHub 自动生成的 Source code 包作为插件安装包。

已安装用户建议先导出提示词备份，再将新版 `extension` 内容更新到原加载目录并点击“重新加载”。保留原目录和扩展 ID，可继续使用已有本地数据。

模型服务需要自己的 API Key 和额度，包内不包含个人密钥或浏览器数据。Windows 置顶辅助程序为可选，使用方式见包内安装说明；macOS 需支持 Document Picture-in-Picture 的 Chrome／Edge，使用时保持原窗口打开。

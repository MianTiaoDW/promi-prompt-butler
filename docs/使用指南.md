# Promi 提示词管家 · 使用指南

适用版本：v1.4.0。主页面有“提示词库”“创作”“图像工坊”三个工作区。

## 1. 安装与打开

从 [Releases](https://github.com/MianTiaoDW/promi-prompt-butler/releases) 下载带插件文件的测试包 ZIP，解压到固定位置。在 Chrome 的 `chrome://extensions/` 或 Edge 的 `edge://extensions/` 开启开发者模式，加载包内的 `extension` 文件夹。源码构建用户加载 `dist`。

点击工具栏中的 Promi 图标打开工作台。首次打开可跟随教程，也可跳过；顶部书本按钮随时可以重看。设置页也支持选择全部六章，选择主页面章节会打开对应工作台引导。

## 2. 连接模型

1. 点击顶部齿轮进入设置，选择服务商。右侧“API 平台”打开官方网页，方便注册、选择模型和创建密钥，不会改变当前服务商选择。
2. 填写 API Key、Base URL，选择文字、视觉和生图模型；模型输入框也支持手动填写模型 ID。
3. 如生图使用不同平台，可单独填写生图密钥与接口地址。密钥、地址和模型需来自对应服务。
4. 设置默认图片比例、分辨率和数量，保存配置并测试连接；绿色连接成功表示最近测试通过。

模型服务和额度由用户准备，实际可用参数以服务商为准。API 平台网页地址不是 Base URL。教程不会替你保存配置或调用模型。

## 3. 提示词库

- 在“全部”查看提示词，输入标题、正文或标签关键词搜索；最近使用便于再次打开刚使用的内容。
- “添加提示词”创建提示词组，可以为一条提示词设置多个步骤。点击卡片查看完整内容、复制或编辑。
- 爱心用于点赞收藏；向上箭头把提示词移到最前；拖动手柄调整顺序；文件夹按钮可关联一个或多个收藏夹。
- 新安装提供 6 条预设，初始不点赞、不放入收藏夹。

### 收藏夹

“我的收藏夹”中点击加号，直接输入名称并确认，可选择十种颜色。拖动文件夹排序，双击标题原地改名，右下角色点修改颜色。

在收藏夹内点击“移出当前收藏夹”，只移除这个关联，提示词仍保留在“全部”；其他收藏夹、点赞和示例图不变。删除收藏夹也不会删除提示词。“全部”列表里的删除会删除提示词本身。

### 示例图

每条提示词最多添加 3 张示例图。悬停图片显示眼睛，点击查看大图；右上角圆底叉号删除该图，双击图片不会删除。“设为示例图”将对应图片用于外面的卡片封面，刷新后保留。

大图中可复制或下载；JPEG／WebP 复制时会转换为 PNG，原图不变。

### 导入与备份

上传按钮导入 ZIP／JSON，先选择方式：追加保留已有内容并跳过重复；覆盖再次确认后替换提示词和收藏夹。下载按钮导出 ZIP，包含提示词、收藏夹、顺序和示例图。

导入提示词不会更改 API 配置或创作历史。覆盖导入前建议先导出备份。

## 4. 创作提示词

1. 在“创作”写主体、场景、风格和氛围，例如“一只小熊站在星空下，3D 卡通风格”。
2. 点击添加参考图，或直接拖入创意描述区域。最多 8 张，按传入顺序排列，缩略图叉号可移除。
3. 选择专家身份、专业工作流和模型，点击生成。
4. 结果可查看中文、英文和结构化 JSON；支持编辑、复制、保存到提示词库，或点击“开始创作”送到图像工坊。

生成和 AI 优化会使用配置的模型服务。等待与失败时显示果冻状态插图，并保留具体状态或错误说明。

## 5. 图像工坊与历史

检查或编辑图片提示词，选择比例、分辨率和张数后生成。生成中可点击取消；完成后点击图片看大图、复制或下载。

生成图片自动保存到浏览器下载目录的 `prompt-butler/创作历史`，手动下载另存到 `prompt-butler/下载图片`。插件显示最新 50 张，最新在前，关闭重开仍保留。旧图超出列表上限后从插件列表移出，已保存的本地文件保留。

## 6. 外观与置顶

顶部主题按钮可选择日间、夜间或跟随系统。连接状态、设置、教程与图钉也在顶部。

- Windows：在扩展管理页复制自己的扩展 ID，运行分享包中的 `windows-pin/install.cmd` 并按提示安装，再重新加载扩展。不安装置顶工具不影响其他主要功能。
- macOS：新版 Chrome／Edge 支持 Document Picture-in-Picture 时，点击图钉直接打开可交互置顶小窗。保持原窗口打开，关闭或刷新原窗口会关闭小窗；两个窗口的未保存输入独立，已保存数据共用。

## 7. 更新、迁移与反馈

更新前先导出提示词备份，再用新版 `extension` 内容更新原加载目录并重新加载，保留原目录与扩展 ID。源码用户拉取最新 main 后运行 `npm ci`、`npm run build`，重新加载 `dist`。

GitHub 只同步代码，浏览器中的设置、个人提示词和历史不会跟随代码同步。迁移提示词请用 ZIP 导出／导入。

反馈问题请提供系统、浏览器、插件版本、步骤、期望与实际结果，以及隐藏密钥后的截图。不要分享 API Key；可填写包内反馈模板或到 [Issues](https://github.com/MianTiaoDW/promi-prompt-butler/issues) 提交。

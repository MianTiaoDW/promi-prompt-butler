# Promi 提示词管家 v1.4.0

- 新增蓝色果冻状态插图，用于欢迎、空列表、搜索无结果、生成等待和失败反馈，适配日间／夜间模式。
- macOS 新版 Chrome／Edge 可通过图钉打开置顶工作台小窗，无需原生辅助程序；使用时需保持原插件窗口打开。
- 修复 JPEG／WebP 示例图复制到剪贴板的兼容性问题。
- 包含收藏夹移出保留提示词、示例图安全删除与封面选择、教程跨章节跳转等已有修复。

安装：下载本页 ZIP 附件并解压，在 Chrome／Edge 扩展管理页打开“开发者模式”，点击“加载已解压的扩展程序”，选择包内 `extension` 文件夹。首次使用需要配置自己的模型服务和 API Key。

更新：先导出提示词备份，将新 `extension` 文件夹的内容更新到原来加载的目录，再点击“重新加载”。保持原目录和扩展 ID，可继续使用原有本地数据。

Windows 置顶仍需按包内说明安装可选辅助程序；不安装不影响其他功能。macOS 小窗与原窗口的未保存输入各自独立，已保存数据共用。

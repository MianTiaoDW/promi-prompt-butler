# Promi 提示词管家 v1.3.1

- 收藏夹支持颜色标签，提示词卡片显示所属收藏夹颜色。
- 简化加号、对勾和关闭图标。
- 修复设置页教程只显示当前章节的问题：现在显示全部六章，选择其他章节会打开对应的主页面引导。
- 修复设置页教程“从头开始”和关闭后再次打开的行为。

下载本页附件 `Promi-v1.3.1-20261019.zip`，解压后在 Chrome／Edge 扩展管理页打开“开发者模式”，点击“加载已解压的扩展程序”，选择 `extension` 文件夹。

已安装用户：先导出提示词备份，将新 `extension` 文件夹中的内容更新到原来加载的目录，再点击“重新加载”。保持原扩展目录和扩展 ID，可继续使用原有本地数据。

首次使用需要配置自己的模型服务和 API Key。Windows 窗口置顶需要按包内说明安装可选辅助程序；macOS 当前不支持窗口置顶，其他功能可用。

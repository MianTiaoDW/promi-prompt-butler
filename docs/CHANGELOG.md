## [1.2.0] - 2026-05-29

### 新增
- 内置默认角色预设："全能AI绘画提示词创意专家"，首次加载自动填入角色设定区，可自由编辑删除
- 种子提示词自动归入各分类下的"默认内置提示词"文件夹，不再散落在分类外层
- 标签页数量徽标：收藏及自定义标签按钮旁显示当前分类下的提示词总数
- 文件夹内添加提示词改为悬浮弹窗，新增标题输入框，确认/取消交互

### 优化
- 移除图像生成区底部冗余状态提示框，提示文字改为按钮下方轻量小字
- 文件夹内"+ 添加提示词"按钮从底部移至标题栏右侧，始终可见无需滚动
- 收藏分类标题栏统一显示"X 条"数量徽标（不再仅"收藏"标签）
- 未分类提示词区域标题加上计数显示
- 配置中心图标背景从三段渐变改为统一主色填充
- 配置中心标题渐变简化，视觉更干净

### 修复
- 清理 v1.1.0 误创建的"收藏/产品精修"等含斜杠的错误自定义标签

## [1.1.0] - 2026-05-22

### 新增
- 内置提示词库：扩展安装时自动导入种子提示词，收藏夹增加「导入内置提示词库」按钮，支持增量导入不重复

- 收藏夹排序：新增置顶、上移、下移操作，提示词按 order 字段排序后回退到时间排序

### 优化
- 收藏夹编辑改为防抖自动保存（1.5 秒），编辑体验更流畅
- 标签页导航支持水平拖拽滚动 + 触摸板滑动
- 删除标签页增加确认按钮，核心标签页不可删除

### 修复
- 修复自定义标签页删除后未正确回退到默认标签页的问题

## [1.0.3] - 2026-05-18

### 新增
- 新增取消生图功能：支持 AbortController 中断正在进行的图像生成请求，UI 增加取消按钮
- 长连接端口保活机制：防止 Service Worker 因闲置被杀导致长任务失败

### 优化
- GPT-Image 尺寸查表映射：支持 1:1 / 4:3 / 16:9 等常见宽高比的精确尺寸输出
- fetchWithRetry 请求重试：网络错误自动重试 2 次（指数退避），超时时间延长至 300 秒
- 轮询次数从 60 次提升至 150 次，配合长任务更可靠

### 修复
- 精简 prompt 端点探测逻辑，移除无用的非版本化路由

## [1.0.0] - 2026-05-16

### 首次发布

#### 核心功能
- **角色设定扩写** — 输入角色预设 + 用户需求，调用大模型生成中文段落、英文 Prompt、结构化 JSON 三种格式
- **收藏夹管理** — 文件夹分类、全文搜索、导入/导出备份、AI 一键优化已有提示词
- **图像生成** — 提示词直出图片，支持单张/批量下载
- **自定义标签** — 自由创建分类，独立管理各自收藏体系

#### 配置中心
- 支持 10+ AI 服务商：Claude / Gemini / ChatGPT / 火山引擎 / Kimi / Deepseek / Minimax / 阿里云百炼 / 小米 / 腾讯云
- API Key 密码框输入，Base URL 自动填充 + 手动修改
- 模型配置支持手填 ID 或下拉预设（推理大模型、视觉模型、生图模型）
- 分辨率（2K/4K）与生成数量（1~4张）参数配置

#### 界面与交互
- 暗黑毛玻璃（Glassmorphism）UI 设计
- 全局悬浮窗，支持拖拽定位
- 实时状态联动（配置未就绪 / 服务已就绪）
- 加载骨架屏动画

#### 技术架构
- Chrome Extension Manifest V3（Service Worker + Content Script + Options Page）
- React 18 + TypeScript + Vite + Tailwind CSS
- chrome.storage.local 本地存储
- Background Service Worker 代理所有 API 请求

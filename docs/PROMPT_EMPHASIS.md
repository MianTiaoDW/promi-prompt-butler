# 提示词画重点

适用于 main 开发版。已有 v1.4.0 标签和朋友测试包保持原样，本次没有重打发布包。

## 使用

在提示词正文中选中一段文字，出现“画重点”色板。选择“背景高亮”或“文字颜色”，可以分别设置或叠加；点击“应用标记”确认。选区工具栏新增 **B 加粗**，点击即可保存加粗，再选中已加粗范围点击可取消；混合选区统一加粗，不影响原有文字色和背景。查看时也可点击已有标记重新设置。

色板会优先放在选中文字旁边，窄窗口则使用选区上方／下方的可用空间并限制高度，内部可滚动，应用按钮固定在底部。调色直接在原文实时预览；关闭或取消不会写入标记，原文恢复已保存的样式。拖动事件按动画帧合并，保留最后落点；色块边界仅在开始拖动时测量，面板位置不跟随每次颜色更新反复计算。

- 阅读预设：红、橙、黄、绿、青、蓝、紫、粉、棕、灰，分别适配背景和文字，以及日间／夜间。
- 自定义：拖动饱和度／明度色块与色相条，也可填写 HEX、饱和度和明度。背景可调不透明度，文字保持不透明。
- 日间／夜间：切换预览并调整对应主题的颜色；预设会同时配置两种主题。
- 颜色组合对比度低于 4.5:1 时提示不易阅读，用户可点击“调整为清晰颜色”。不静默修改自选颜色。
- 清除当前类型或选区全部标记；Esc、关闭按钮或点击其他区域收起色板。

## 覆盖与保存

新建／编辑提示词步骤、查看步骤与中英／JSON 版本、创意描述与专家身份、创作生成结果，以及图像工坊提示词均使用相同色板。卡片摘要会显示已有标记。

已保存内容的标记点击应用即保存；新建或编辑中的标记随正文确认／保存。创作工作区和图像工作区使用原本的本地存储，生成结果编辑也保存到当前任务结果，重开后文本和标记对应。ZIP 导出／导入保留标记。标记按文字位置保存，同一句出现多次时只影响所选的一处。

普通编辑按未变化的前后片段保留／移动标记，替换范围内的标记会清除，避免标到新内容上；在标记内部插入文字会继承该标记。整体替换或复杂 JSON 重排可能清除受影响范围的标记，需要重新确认。

复制、步骤拼接、发送到图像工坊和模型请求均保留纯文字；颜色与加粗属于单独的可选数据，不插入 HTML 或颜色代码。没有引入新的编辑器或调色依赖。

## 加粗（2026-10-27）

加粗使用独立的 `kind: bold` 标记，与背景和文字颜色共用选区、位置调整及保存链路。保留共享数据结构的 light/dark 中性色字段，但渲染加粗时忽略它们；旧的两类颜色标记不需迁移。清除全部会同时去掉加粗，清除颜色不会去掉加粗。

阅读正文、步骤、卡片和预览使用 700 字重。编辑框沿用 textarea 镜像，镜像以轻微文字描粗保持字宽，避免破坏光标、换行和选区对齐；不改为富文本编辑器。复制和模型请求仍是纯文字，不插入 Markdown 星号或 HTML。

验证：`test-prompt-bold.cjs` 覆盖完整／部分／混合选区、相邻覆盖、取消、颜色独立、编辑与 Unicode；`test-mark-persistence.cjs` 覆盖颜色＋加粗 ZIP 往返；`test-prompt-bold-ui.cjs` 在真实隔离扩展验证 B 选中反馈、700 字重、只加粗不误保存色板预览、刷新、日夜及 420px，原有 `test-prompt-emphasis.cjs` 完整回归通过。截图 `output/playwright/bold-*.png`。

# Promi 提示词管家 v1.3.3

- 修复收藏夹内删除提示词会永久删除的问题：现在只移出当前收藏夹，提示词仍在“全部”中。
- 保留提示词的其他收藏夹关联、点赞和示例图，兼容旧版收藏夹数据。
- 收藏夹内按钮提示改为“移出当前收藏夹”。
- 包含前版示例图安全删除、悬停查看大图和卡片示例图切换。

下载附件 `Promi-v1.3.3-20261019.zip`，解压后在 Chrome／Edge 扩展管理页打开“开发者模式”，点击“加载已解压的扩展程序”，选择 `extension` 文件夹。

已安装用户：先导出提示词备份，将新 `extension` 文件夹中的内容更新到原来加载的目录，再点击“重新加载”。保持原扩展目录和扩展 ID，可继续使用原有本地数据。

首次使用需要配置自己的模型服务和 API Key。Windows 置顶为可选功能，安装方式见包内使用说明；macOS 当前不支持窗口置顶，其他功能可用。

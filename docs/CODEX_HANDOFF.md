## 2026-10-12 最新正式插件

### 最新功能：收藏夹、排序与编辑

- 2026-10-11 修复持久写入覆盖：提示词／收藏夹的改动经 Background 统一排队，基于原始快照仅合并改变的字段；使用记录、排序、旧图片迁移不覆盖并发编辑。步骤保存等待后台成功，失败保留草稿并显示错误。已验证并发写入、保存故障与重试、关闭重开以及浏览器重启后的步骤标题和排序持久化。

- 提示词库移除分类栏；旧分类里的提示词仍在“全部”可访问，旧收藏夹及内容保持可访问。
- 卡片新增“收藏到文件夹”，弹窗可选择现有收藏夹或新建后直接选中；同一提示词可进入多个收藏夹，不自动点赞。缺失 `isFavorite` 标记按未点赞显示。
- “全部”“收藏”和收藏夹内卡片通过拖动手柄调整顺序，共享一个持久顺序；筛选列表仅调整可见卡片，其他卡片保留位置。收藏夹支持跨旧分类拖动排序。
- 点击、复制、编辑、点赞及加入收藏夹不改变卡片顺序；新增提示词追加在已排好顺序之后。备份保留排序与收藏夹归属。
- 本地验证：`npm run build`（含类型检查）及 `node scripts/test-prompt-organization.cjs` 通过。在隔离 Chromium 中加载真实 `dist`，完成三处拖动、文件夹选择／新增、旧内容访问、刷新与浏览器重启后持久化检查；420／680／980px 控件和弹窗未越界，无页面脚本异常。未调用真实 AI 或改动用户浏览器数据。

- 卡片支持拖动时半透明让位预览和弹簧换位，松手才保存，取消拖动恢复原位；收藏夹同样支持。
- 创作结果取消“加入常用”与独立编辑图标；点击正文编辑，仅编辑时显示取消／确认。保存图标改为带加号书签，保存弹窗移除分类，名称和标签带示例与内边距；创意描述不再显示字数。
- 输入框支持 Enter 确认，也可编辑后点击插件内空白处确认；切换输入框和取消按钮不提交。多行输入用 Shift+Enter 换行，输入法选字不提交。创意描述／图像提示词按 Enter 结束输入，不触发收费生成。
- 删除收藏夹使用约 2 秒底部通知；步骤编辑保存失败保留草稿，成功后才退出。正文编辑不再出现绿色焦点边线。
- 2026-10-12 验证：生产构建、排序／并发持久化回归测试通过；隔离 Chromium 加载真实扩展验证拖动预览与取消、保存和编辑、回车与空白处确认、中文输入法保护、配置保存、重启后标题和顺序保留。测试使用隔离数据，未调用真实 AI。

以本分支当前 `src/` 为准：黑色背景、灰色层级、绿色操作，导航为提示词库／创作／图像工坊。

- 移除旧的 186 条内置提示词及自动导入入口；用户收集的内容保留。
- 通过收藏夹整理内容，分类栏已移除；旧分类数据仍在“全部”可访问。
- 手动提示词组支持标题、备注、多步骤，步骤卡片可复制、编辑、删除；整组可再次编辑。
- 手动组不显示创作专用英文／JSON／状态／AI 操作，示例图显示在外层卡片右侧。
- 编辑弹窗定位到插件窗口内，避开顶部栏，内容内部滚动。

## 另一台电脑首次接续

```powershell
git clone https://github.com/MianTiaoDW/prompt-butler.git
cd prompt-butler
git fetch origin
git switch main
npm install
npm run typecheck
npm run build
```

若公司电脑已经克隆过旧仓库：

```powershell
git status --short --branch
git fetch origin
git switch main
git pull --ff-only
npm install
npm run build
```

切分支前若 `git status` 有公司电脑自己的修改，不要覆盖；先提交到独立分支或暂存并说明来源。

给另一台电脑 Codex 的第一条指令：

> 完整阅读 `AGENTS.md`、`docs/CODEX_HANDOFF.md`、`README.md`，检查当前分支、Git 状态和最近提交。以最新 `main` 为正式基准。当前正式插件采用黑绿配色，以 src/ 下最新代码为准；设计实验和旧截图不应覆盖正式界面。

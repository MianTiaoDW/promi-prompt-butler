# Promi 提示词管家 v1.3.2

- 示例图右上角新增圆底叉号，只有点击叉号才删除，避免误操作。
- 悬停示例图显示眼睛，点击查看大图，双击不会删除。
- 每张图下方新增“设为示例图”，可切换提示词卡片显示的图片，刷新后保留。
- 包含 v1.3.1 的收藏夹颜色标签及新手教程跨章节修复。

下载附件 `Promi-v1.3.2-20261019.zip`，解压后在 Chrome／Edge 扩展管理页打开“开发者模式”，点击“加载已解压的扩展程序”，选择 `extension` 文件夹。

已安装用户：先导出提示词备份，将新 `extension` 文件夹中的内容更新到原来加载的目录，再点击“重新加载”。保持原扩展目录和扩展 ID，可继续使用原有本地数据。

首次使用需要配置自己的模型服务和 API Key。Windows 置顶为可选功能，安装方式见包内使用说明；macOS 当前不支持窗口置顶，其他功能可用。

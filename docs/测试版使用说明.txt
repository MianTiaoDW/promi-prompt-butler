Promi 提示词管家 1.4.0 朋友测试版

一、安装插件
1. 把整个压缩包解压到一个固定位置。
2. Chrome 地址栏输入 chrome://extensions/；Edge 输入 edge://extensions/。
3. 打开“开发者模式”，点击“加载已解压的扩展程序”。
4. 选择解压目录里面的 extension 文件夹。
5. 点击浏览器工具栏中的插件图标，打开 Promi。

请保留解压文件夹，使用期间不要移动或删除。
如果已经安装过旧版，建议用新 extension 目录的内容更新原来加载的目录，再点击“重新加载”，这样可保留原扩展的数据。

二、第一次使用
首次打开会出现新手教程，可以从头开始、按章节查看，也可以跳过。
以后点击顶部书本图标可以重新查看。设置页也有独立的设置教程。
测试包提供 6 条默认提示词，不会自动点赞或加入收藏夹。

三、连接模型
点击顶部设置，选择服务商。
服务商列表右边的“API 平台”打开官方网站，注册／登录后选择模型、创建 API Key。
把密钥、接口地址和模型 ID 填回插件，保存配置，再测试连接。
模型服务需要你自己的账号和额度，测试包不包含 API Key。
API 平台网页地址不是 Base URL，接口地址请以平台文档为准。

四、提示词库
可以新建多步骤提示词组、搜索、复制、编辑、点赞、加入收藏夹、置顶、排序和查看示例图。
收藏夹支持红、橙、黄、绿、青、蓝、紫、黑、白、灰十种颜色。点击文件夹右下方的小圆点可改色，卡片左上角圆点表示所属收藏夹。
导入支持 ZIP／JSON：追加保留已有内容并跳过重复，覆盖会替换提示词和收藏夹，操作前会再次确认。
导出 ZIP 可以备份或分享自己的提示词和示例图。
收藏夹内的移出只取消当前收藏夹关联，提示词仍保留在全部中；全部列表的删除会删除提示词。
示例图悬停显示眼睛，点击查看大图；右上角叉号删除该图片，下方“设为示例图”切换卡片显示的图片。

五、创作与生图
在“创作”里描述想法，参考图支持点击添加或拖入，最多 8 张。
选择专家身份、工作流和模型后生成提示词，可以编辑、复制或保存，再送到图像工坊。
图像工坊可设置比例、分辨率和张数，生成中可取消。
生成图片自动保存到浏览器下载目录的 prompt-butler／创作历史；手动下载另存到 prompt-butler／下载图片。
插件历史显示最新 50 张，最新在前，关闭重开仍保留。

六、可选：Windows 窗口置顶
不安装置顶辅助程序，不影响其他功能。
如需置顶：先在扩展管理页找到本插件的扩展 ID（32 位英文字母），复制它。
双击 windows-pin 文件夹中的 install.cmd，按提示粘贴扩展 ID，回车安装。
安装完成后重新加载扩展，再点击顶部图钉。
安装程序只为当前 Windows 用户注册辅助程序，使用 Windows 自带的 .NET Framework，不需要安装 Node.js 或 .NET SDK。
macOS：新版 Chrome／Edge 可直接点击图钉打开置顶小窗，不需要安装 Windows 辅助程序。若浏览器提示不支持，请升级浏览器。
使用 macOS 置顶小窗时，请保持原插件窗口打开；关闭或刷新原窗口也会关闭小窗。两个窗口未保存的输入各自独立，已保存的数据共用。
